# Natural Resources™ — Pure Living Hydration & Water Supply

> **Artisanal Glacial Bottled Water Brand & Smart Urban Water Supply Logistics**

![Natural Resources Brand Preview](https://images.unsplash.com/photo-1548839140-29a749e1bc4e?auto=format&fit=crop&w=1200&q=80)

An ultra-premium, interactive, animated Next.js web platform engineered for **Natural Resources™**, a luxury living water company specializing in high-altitude spring bottled water, smart residential & commercial 5-gallon carboys, touchless smart dispensers, and bulk food-grade tanker logistics.

---

## 🌟 Key Highlights & Features

### 1. 💧 Dynamic Audio-Visual Hero Experience
- **Interactive Fluid Water Ripples Canvas**: Cursor and pointer movements generate real-time fluid ripples, refractions, and floating mineral bubbles.
- **Ambient Mountain Spring Sound Synthesizer**: Built using native **Web Audio API** (pink noise + resonant bandpass filters + low-frequency surge oscillators) to produce a soothing, authentic alpine stream sound on demand without requiring external audio downloads.
- **Interactive 3D-Feel Bottle Visualizer**:
  - Interactive mouse tilt physics with reactive lighting highlights.
  - Multi-tier product switcher:
    - *Glacier Diamond Reserve (750ml Artisanal Glass)*
    - *5-Gallon Eco-Carboy (19L Doorstep Refill)*
    - *Alkaline+ 8.8 Active Cellular Hydration*
    - *Bulk Food-Grade Tanker Logistics (5,000L - 25,000L)*
- **Live Fleet Dispatch Pill**: Real-time fleet status indicator (*"🟢 Fleet Dispatch: Active (35m)"*).

### 2. 🧮 Interactive Hydration & Delivery Calculator
- Users can adjust:
  - Number of household members or office personnel (1 to 50+).
  - Daily activity intensity (Sedentary, Active Living, High-Performance Athletic).
  - Delivery frequency (Weekly, Bi-weekly, Monthly).
- Dynamically outputs:
  - Exact daily and monthly liter requirements.
  - Recommended bottle and jug combo (5-Gallon carboys + Glass cases).
  - **Live Environmental Impact Metric**: Single-use plastic bottles prevented from landfills.
  - Automated 15% recurring subscription savings discount.

### 3. 🛍️ Master Water Catalog & Interactive Cart
- Categorized filter tabs: *All Collections, Artisanal Glass, 5-Gallon & Dispensers, Bulk Fleet, Gear*.
- 8 meticulously crafted products with authentic mineral composition, volume, pH, and TDS metrics.
- Confetti celebration upon adding items to cart.
- Slide-out Cart Drawer with quantity adjustment, 15% subscription toggle, free doorstep pickup credit, and instant checkout.
- Detailed technical popup modal for every bottle.

### 4. 🔬 The 8-Stage Purity Journey
- Interactive step-by-step exploration of Natural Resources' proprietary purification:
  1. *Protected Glacial Catchment*
  2. *Multi-Depth Sediment Clarification*
  3. *Silver-Catalyzed Activated Carbon*
  4. *Dual-Pass Precision Nano-Filtration (0.0001 Micron)*

### 5. 🧪 Mineral Purity Lab & Interactive TDS Dial

### 7. 🏢 Enterprise & Corporate Water Solutions

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router, React 19, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com) (v4) with custom glassmorphism, glowing cyan caustics, and water shimmer effects
- **Audio Engine**: Native HTML5 Web Audio API (real-time procedural stream synthesis)
- **Icons**: [Lucide React](https://lucide.dev)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Optimization**: Zero external network font dependencies; builds and runs completely offline and blisteringly fast.

## 🚀 Running the Project Locally

```bash
# Clone or open the project directory
cd d:/personal/natural-resources

# Run the development server
npm run dev

# Or build and run for production
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience **Natural Resources™ Pure Living Hydration**.
